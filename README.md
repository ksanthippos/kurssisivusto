# RAUH - Kurssisivusto

Matematiikan ja fysiikan oppimateriaalit ja teoriasivusto (Pasilan peruskoulu).
Tämä sivusto toimii modernina, mobiiliystävällisenä korvaajana aiemmalle Google Sites -sivustolle.

## Ominaisuudet
- **Responsiivinen ulkoasu**: Optimoitu toimimaan sulavasti niin puhelimella kuin tietokoneella.
- **KaTeX-kaavatuki**: Matemaattiset ja fysikaaliset kaavat renderöityvät nopeasti ja veitsenterävästi.
- **Interaktiiviset simulaatiot**: PhET- ja Geogebra-upotukset toimivat suoraan oppitunneilla.
- **Yhteensopivuus kurssiportaaliin**: Oppitunnit ja aiheet vastaavat suoraan RAUH-kurssiportaalia.
